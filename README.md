# 🌿 Casa Verde

A full-stack plant management and care tracking application with an AI-powered plant assistant.

## Tech Stack

**Frontend:** React 19, TypeScript, Vite, Tailwind CSS, React Router, Lucide React  
**Backend:** Node.js, Express, Groq API, Helmet, Express Rate Limit, CORS  
**Database:** Supabase

## Features

- Plant management and profiles
- Care activity logging
- Plant care history
- AI-powered plant care assistant
- Supabase database integration
- Protected backend API with rate limiting and API authentication
